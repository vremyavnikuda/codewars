# Документация для скрипта show_processes.sh

## Обзор

Этот скрипт предназначен для отображения активных процессов в системе Arch Linux с подробной информацией и различными способами фильтрации и сортировки.

## Пошаговое объяснение работы скрипта

### 1. Заголовочная информация
```bash
#!/bin/bash
```
- `#!/bin/bash` - шебанг, указывает системе, что скрипт должен выполняться интерпретатором bash

```bash
echo "Активные процессы на Arch Linux:"
echo "========================================"
```
- `echo` - команда для вывода текста в терминал
- Выводит заголовок и разделитель для улучшения читаемости

### 2. Отображение всех активных процессов
```bash
ps -eo pid,ppid,stat,comm,user,%cpu,%mem,time,args --sort=-%cpu | awk 'NR == 1 || $3 ~ /^[RSDTZ]/ {print}'
```

#### Объяснение команды `ps`:
- `ps` - команда для отображения информации о процессах
- `-e` - показывает все процессы в системе
- `-o` - позволяет указать конкретные поля для отображения:
  - `pid` - идентификатор процесса (Process ID)
  - `ppid` - идентификатор родительского процесса (Parent Process ID)
  - `stat` - состояние процесса
  - `comm` - имя команды
  - `user` - пользователь, запустивший процесс
  - `%cpu` - процент использования CPU
  - `%mem` - процент использования памяти
  - `time` - время процессора, которое процесс использовал
  - `args` - аргументы командной строки

- `--sort=-%cpu` - сортировка по убыванию по использованию CPU (знак "-" означает убывающий порядок)

#### Объяснение команды `awk`:
- `awk` - мощная утилита для обработки текста и шаблонов
- `NR == 1` - первая строка (заголовок) всегда выводится
- `||` - логическое ИЛИ
- `$3` - третий столбец (в данном случае - stat - состояние процесса)
- `~` - оператор соответствия шаблону
- `/^[RSDTZ]/` - регулярное выражение, которое означает:
  - `^` - начинается с
  - `[RSDTZ]` - любая из перечисленных букв
  - R - Running (работающий на CPU)
  - S - Sleeping (спящий, прерываемый сон)
  - D - Uninterruptible sleep (непрерываемый сон, обычно ввод/вывод)
  - T - Stopped (остановленный)
  - Z - Zombie (зомби-процесс, завершен, но все еще в таблице процессов)
- `{print}` - вывод строки, если условие выполняется

### 3. Процессы с наибольшим использованием CPU
```bash
ps -eo pid,stat,comm,user,%cpu,%mem --sort=-%cpu | awk 'NR == 1 || (NR > 1 && $2 ~ /^[RSDTZ]/)' | head -15
```

#### Объяснение:
- `ps -eo pid,stat,comm,user,%cpu,%mem` - получение только важных полей
- `--sort=-%cpu` - сортировка по CPU в порядке убывания
- `awk 'NR == 1 || (NR > 1 && $2 ~ /^[RSDTZ]/)'` - фильтрация строк:
  - Или это заголовок (NR == 1)
  - Или это данные строки (> 1) и второй столбец (stat) соответствует активному состоянию
- `head -15` - показывает только первые 15 строк (включая заголовок, т.е. 14 процессов)

### 4. Процессы с наибольшим использованием памяти
```bash
ps -eo pid,stat,comm,user,%cpu,%mem --sort=-%mem | awk 'NR == 1 || (NR > 1 && $2 ~ /^[RSDTZ]/)' | head -15
```

#### Объяснение:
- Аналогично предыдущей команде, но с сортировкой по памяти (`--sort=-%mem`)
- Показывает процессы, отсортированные по использованию памяти в порядке убывания

### 5. Дерево процессов
```bash
pstree -p
```

#### Объяснение:
- `pstree` - команда, которая отображает процессы в виде древовидной структуры
- `-p` - показывает идентификаторы процессов (PID) рядом с именами процессов
- Показывает иерархию процессов - какие процессы являются дочерними для других

### 6. Справочная информация о состояниях процессов
```bash
echo "Справка по состояниям процессов:"
echo "  R - Running или выполнение на CPU"
echo "  S - Sleeping (прерываемый сон)"
echo "  D - Uninterruptible sleep (обычно ввод/вывод)"
echo "  T - Stopped (например, сигналом SIGTSTP)"
echo "  Z - Zombie (мертвый, но все еще в таблице процессов)"
```
- Просто выводит информацию для объяснения значений кодов состояний процессов

### 7. Информация о системной нагрузке
```bash
uptime
```
- `uptime` - команда, которая показывает:
  - Текущее время
  - Сколько времени система работает с момента последнего запуска
  - Количество активных пользователей
  - Среднюю загрузку системы за последние 1, 5 и 15 минут

## Коды состояний процессов

| Символ | Значение | Описание |
|--------|----------|----------|
| R | Running | Процесс выполняется или готов к выполнению |
| S | Sleeping | Процесс спит (ожидает событие или таймер) |
| D | Uninterruptible Sleep | Не прерываемый сон (обычно дисковый I/O) |
| T | Stopped | Процесс остановлен (например, сигналом SIGTSTP) |
| Z | Zombie | Зомби-процесс (процесс завершился, но родитель не получил уведомление) |

## Поля вывода команды ps

| Поле | Описание |
|------|----------|
| PID | Идентификатор процесса |
| PPID | Идентификатор родительского процесса |
| STAT | Состояние процесса |
| COMMAND | Имя команды |
| USER | Пользователь, запустивший процесс |
| %CPU | Процент использования CPU |
| %MEM | Процент использования памяти |
| TIME | Время процессора, использованное процессом |
| ARGS | Аргументы командной строки |

## Применение

Этот скрипт полезен для:
- Мониторинга активных процессов в системе Arch Linux
- Определения процессов, потребляющих больше всего CPU или памяти
- Понимания иерархии процессов
- Диагностики проблем производительности системы
