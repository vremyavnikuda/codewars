# Документация по скриптам командной строки

## Обзор скриптов

В этой директории находятся три shell-скрипта, разработанные для выполнения различных задач:

1. **string_compare.sh** - сравнение строк
2. **max_two_integers.sh** - нахождение максимального из двух целых чисел
3. **max_four_integers.sh** - нахождение максимального из четырёх целых чисел

---

## Скрипт 1: string_compare.sh

### Описание
Этот скрипт принимает два строковых параметра и выводит:
- Название скрипта
- Значения обоих параметров
- Сообщение о равенстве или неравенстве строк

### Параметры
- `$1` - первая строка для сравнения
- `$2` - вторая строка для сравнения

### Как использовать
```bash
./string_compare.sh <строка1> <строка2>
```

### Примеры
```bash
./string_compare.sh "hello" "world"     # Строки различаются
./string_compare.sh "test" "test"       # Строки одинаковы
```

### Вывод
Скрипт выводит информацию о названии скрипта, параметрах и результате сравнения строк.

---

## Скрипт 2: max_two_integers.sh

### Описание
Этот скрипт принимает два целых числа и выводит:
- Оба параметра
- Максимальное из двух чисел

### Параметры
- `$1` - первое целое число
- `$2` - второе целое число

### Как использовать
```bash
./max_two_integers.sh <число1> <число2>
```

### Примеры
```bash
./max_two_integers.sh 15 23            # Выведет 23 как максимум
./max_two_integers.sh -5 10            # Выведет 10 как максимум
./max_two_integers.sh 7 7              # Оба числа равны
```

### Валидация
Скрипт проверяет, что оба параметра являются целыми числами. Если нет, выводится сообщение об ошибке.

---

## Скрипт 3: max_four_integers.sh

### Описание
Этот скрипт принимает четыре целых числа и выводит:
- Все четыре параметра
- Максимальное из четырёх чисел

### Параметры
- `$1` - первое целое число
- `$2` - второе целое число
- `$3` - третье целое число
- `$4` - четвёртое целое число

### Как использовать
```bash
./max_four_integers.sh <число1> <число2> <число3> <число4>
```

### Примеры
```bash
./max_four_integers.sh 10 25 5 30       # Выведет 30 как максимум
./max_four_integers.sh -3 -1 -7 -2      # Выведет -1 как максимум
./max_four_integers.sh 100 50 75 25     # Выведет 100 как максимум
```

### Валидация
Скрипт проверяет, что все четыре параметра являются целыми числами. Если нет, выводится сообщение об ошибке.

## Перенаправление вывода

Все скрипты поддерживают перенаправление стандартного вывода в файл с использованием оператора `>`.

### Примеры перенаправления

#### string_compare.sh
```bash
./string_compare.sh "apple" "banana" > outa
```
Вывод будет записан в файл `outa`.

#### max_two_integers.sh
```bash
./max_two_integers.sh 45 32 > outb
```
Вывод будет записан в файл `outb`.

#### max_four_integers.sh
```bash
./max_four_integers.sh 12 8 45 23 > outc
```
Вывод будет записан в файл `outc`.

### Проверка содержимого файлов
```bash
cat outa  # Просмотр содержимого файла outa
cat outb  # Просмотр содержимого файла outb
cat outc  # Просмотр содержимого файла outc
```

## Ошибки и обработка исключений

Все скрипты проверяют количество переданных параметров:
- string_compare.sh требует ровно 2 параметра
- max_two_integers.sh требует ровно 2 параметра (оба должны быть целыми числами)
- max_four_integers.sh требует ровно 4 параметра (все должны быть целыми числами)

Если количество или тип параметров не соответствует требованиям, скрипт выводит сообщение об использовании и завершает выполнение с кодом 1.
